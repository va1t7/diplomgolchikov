# STEPUP — интернет-магазин обуви

## Описание
Веб-приложение для продажи обуви с каталогом, корзиной, оформлением заказов и административной панелью.

## Возможности
- Просмотр каталога.
- Фильтрация товаров.
- Добавление в корзину.
- Оформление заказа.
- Личный кабинет.
- Панель для менеджера, логиста и HR-аналитика.

## Технологии
PHP, MySQL, HTML, CSS, JavaScript, XAMPP.

## Установка
1. Скопировать проект в папку `htdocs`.
2. Импортировать `schema.sql` в MySQL.
3. Настроить `config/db.php`.

## Запуск
1. Запустить Apache и MySQL в XAMPP.
2. Открыть `http://localhost/store/`.
